# Design System

CSS variables for semantic tokens: --color-primary, --color-success, --color-warning, --color-danger, --color-surface, --color-text, --color-muted. Components use semantic tokens rather than literal hex. Define type scale: 12,14,16,18,20,24,32px; body default 16px. Focus ring 2px high contrast; error/success icons + text. Motion 120–250ms, respects prefers-reduced-motion. Light theme MVP; dark theme P2. Use SVG/icon assets with verified licensing, no arbitrary downloaded media.
