# Game Rules — 6 MVP Games

## 1 Picture Match
Prompt word/audio -> choose 1 image from 4; distractors distinct and same topic where possible. Keyboard numbered choices. Evaluate image ID.
## 2 Memory Flip
4–8 pairs by level; word/translation pairs; matching pair persists face up. Score based on completed board, not each click. Ensure no ambiguous translations. Accessible list-based alternative to visual flipping.
## 3 Sentence Builder
Reorder word tokens; evaluate token IDs in canonical sequence; allow alternate accepted sequences if grammatical and semantically equivalent, authored explicitly. Click-to-order and undo; no drag requirement.
## 4 Error Detective
Highlight error segment and choose correction; avoid multiple valid corrections unless explicitly accepted. Explanation names grammar concept. Allow no-error questions only if clearly indicated.
## 5 Listen & Choose
Audio of word/sentence -> 4 options; audio replay, load/error state; transcript only after submission if it gives away answer. Human-reviewed audio text alignment.
## 6 Roleplay Simulator
Scripted decision tree; situation, NPC turn, 2–4 choices, branching outcomes. Author 'appropriate', 'acceptable', 'inappropriate' ratings with contextual explanation. No free-form AI in MVP. Finish on success/terminal branch, bounded max turns.

## Content validation
Each question must have skill, CEFR-like difficulty tag, topic, correct answer/rubric, explanation, status and reviewedBy. Publish only reviewed content. All distractors checked for ambiguity.
